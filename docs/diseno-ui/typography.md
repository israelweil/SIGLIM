# Tipografía y Jerarquía - SIGLIM

## 1. Familia Tipográfica
- **Fuente Principal**: Inter / Roboto / System Sans-Serif (`font-sans`).
- **Fuente Monospace**: JetBrains Mono / Consolas (para marcadores, estadísticas numéricas y códigos federativos).

| Nivel | Tamaño (approx) | Peso | Interlineado | Uso Principal |
| :--- | :--- | :--- | :--- | :--- |
