# Diseños de Disposición (Layouts) y Navegación - SIGLIM

## 1. Navegación Global (Header)
- **Ubicación**: Fija en la parte superior de todas las páginas públicas e internas.
- **Elementos**:
  - Logotipo institucional con insignia de temporada.
  - Menú de navegación principal: *Partidos y Resultados*, *Clasificación*, *Equipos*, *Estadísticas*, *Torneos*.
  - Selector desplegable de división (ej. *Primera División ▾*).
  - Icono de búsqueda global.
  - Botón destacado de acción: *Portal Delegados / Gestión* acompañado del avatar de usuario.

## 2. Estructura de Contenido
- Contenedores centrados con ancho máximo (`max-w-7xl`).
- Distribución en rejilla (Grid) para secciones de partidos, widgets de estadísticas y clasificaciones.
